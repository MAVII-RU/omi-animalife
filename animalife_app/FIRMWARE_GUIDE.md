# Прошивка XIAO nRF52840 Sense для AnimalLife

## Что нужно

- Устройство: Seeed Studio XIAO nRF52840 Sense
- Кабель: USB-C
- Компьютер: Windows / macOS / Linux
- Прошивка: файл `.uf2` из релизов omi

---

## Шаг 1 — Скачать прошивку

1. Открой https://github.com/BasedHardware/omi/releases
2. Найди последний релиз → раздел **Assets**
3. Скачай файл с именем вида `omi-firmware-xiao-*.uf2`

> Стандартная прошивка omi уже настроена на передачу аудио (Opus 16кГц mono).
> Для AnimalLife дополнительная настройка прошивки **не требуется**.

---

## Шаг 2 — Перевести устройство в режим загрузчика

1. Подключи устройство к компьютеру через USB-C
2. **Дважды быстро нажми кнопку RESET** (маленькая кнопка на плате)
   - Между нажатиями менее 0.5 секунды
3. На компьютере появится диск: `XIAO-SENSE` или `FTHRS52BOOT`

> Если диск не появился — попробуй ещё раз. Двойной клик должен быть быстрым.

---

## Шаг 3 — Установить прошивку

1. Перетащи скачанный `.uf2` файл на диск `XIAO-SENSE`
2. Устройство автоматически перезагрузится (диск исчезнет)
3. Готово — прошивка установлена

> На macOS: может появиться ошибка «Диск извлечён неправильно» — это нормально.

---

## Шаг 4 — Проверить работу

1. Открой приложение AnimalLife Device
2. Нажми иконку Bluetooth (🔵) в правом верхнем углу
3. Нажми «Найти omi устройства»
4. Устройство появится в списке → нажми «Выбрать»
5. Вернись к питомцу → нажми «Слушать»

---

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Диск не появляется | Попробуй другой кабель (нужен data-кабель, не зарядный) |
| Устройство не находится в BLE-сканировании | Проверь что прошивка omi (не другая) |
| Аудио не передаётся | Убедись что устройство заряжено (> 20%) |
| Устройство мигает красным | Разряжен аккумулятор, зарядить |

---

## Технические параметры прошивки omi

| Параметр | Значение |
|---|---|
| Аудио кодек | Opus |
| Частота сэмплирования | 16 кГц |
| Каналы | Mono |
| BLE сервис UUID | `19b10000-e8f2-537e-4f6c-d104768a1214` |
| Аудио характеристика UUID | `19b10001-e8f2-537e-4f6c-d104768a1214` |
| Codec характеристика UUID | `19b10002-e8f2-537e-4f6c-d104768a1214` |

---

## Почему стандартная прошивка подходит

Устройство работает как микрофон: непрерывно записывает звук и передаёт по BLE.
Фильтрация (VAD — определение звуков животных) работает **на сервере**:

```
XIAO → Opus аудио → BLE → Телефон → WebSocket → animapp.ru
     → Gemini/Qwen анализирует → отфильтровывает речь и фон
     → возвращает только перевод звуков питомца
```

Менять прошивку нужно только если хочешь:
- Записывать только при звуке (аппаратный VAD) — экономия батареи
- Другое качество аудио (48 кГц)

В таком случае — обратись в поддержку AnimalLife.
